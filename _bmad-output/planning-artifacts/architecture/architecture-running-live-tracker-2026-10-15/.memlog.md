- (decision) Paradigm: append-only fix log on server with derived projections (CQRS-lite); phone uses store-and-forward outbox. Binds all; prevents stats being stored as mutable truth or computed in multiple places
- (decision) Server is sole computer of derived stats (distance, current/avg pace, course progress, ETA); phone sends raw fixes only; browser renders and only ticks wall-clock-dependent values (elapsed, last-update age) locally from server timestamps. Prevents phone/web/server disagreeing on numbers
- (decision) Ingest: POST /api/v1/ingest batch, Bearer runner key; idempotent on (runner_id, session_id, seq); ack = highest contiguous seq; phone deletes acked outbox rows. Prevents duplicate fixes on resend and lost fixes
- (decision) Tracking session: app generates UUIDv4 session_id on Start; seq monotonic per session from 0; Stop enqueued as terminal 'end' record in same outbox so it's ordered after last fix. Prevents start/stop drift and out-of-order stop
- (decision) Live push via SSE GET /api/v1/live: snapshot event on connect then delta events; 20s heartbeat comment; client reconnects and takes fresh snapshot (no Last-Event-ID replay). Prevents bespoke polling and stale state after reconnect
- (decision) Wire: JSON, camelCase, epoch ms UTC integers, SI units (m, s, m/s); min/km formatting only in web UI. Contract source of truth: shared/src/contract.ts (zod schemas) for server+web; Android mirrors by hand with contract tests against fixtures in shared/fixtures
- (decision) Storage: single SQLite file (WAL) owned by server store module; only ingest writes fixes; projections are in-memory and rebuilt from the log at boot. Event config (runners, keys, course) from config file loaded at boot, read-only at runtime
- (decision) Course progress: project each fix onto GPX polyline, forward-only search window from last matched distance (handles crossings/out-and-back); progress never decreases; off-course > threshold keeps last progress. Distance stat = course progress when course present else filtered GPS track distance
